# Yaloak Estate 股东资产价值报告

> 报告日期：2026-04-21  
> 数据来源：[[10_Projects/Yaloak Estate/attachments/Yaloak Rates.xlsx]]

## 1. 结论摘要

- 2025/26 相比 2024/25，当前 6 个资产的 **Site Value 合计下降 A$7,850,000（-10.4%）**。
- 同期 **Capital Improved Value 合计下降 A$7,850,000（-10.1%）**。
- 按公司拆分：
  - **Harvest Agriculture**：Site Value 下降 A$7,300,000，CIV 下降 A$7,250,000。
  - **SY Trust, SY Pty Ltd**：Site Value 下降 A$550,000，CIV 下降 A$600,000。
- 下降最明显的资产是 **Glenmore Road（123125）**，其 Site Value 和 CIV 均下降 A$4.0m。
