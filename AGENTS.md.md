# Obsidian Investment System

## Scope
This is an Obsidian vault for an investment management platform.

## Core Structure

- 01_Wiki → knowledge, models, frameworks
- 02_Research → new investment opportunities
- 03_Projects → active investments
- 04_Reports → outputs
- 09_System → agents, skills, rules

## Rules

- Do NOT modify `.obsidian/` unless explicitly instructed
- Follow folder structure strictly
- Keep Chinese naming for projects
- Use DD-MM-YYYY format for dates

## Research Workflow

When a new investment idea appears:

1. Create a file under:
   02_Research/01_在研究/

2. Use structure:
   - basic info
   - thesis
   - risks
   - next steps

3. If promoted:
   move to → 02_Research/02_推进中

4. If rejected:
   move to → 02_Research/03_不买

5. If approved:
   move to → 03_Projects/

## Project Workflow

Each project must have:

- Overview
- Thesis
- Updates
- Actions
- Materials
- Meetings
- Decisions

## Commands Preference

- Prefer structured notes over free text
- Prefer editing existing files over creating duplicates
- Always maintain links between notes
