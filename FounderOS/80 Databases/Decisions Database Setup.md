# Decisions Database Setup

## Purpose

Use this setup note to create an Obsidian Bases view when the local Bases format is confirmed.

## Filter

- Include notes where `type` or folder location matches `decisions`.

## Display Fields

- `date`
- `project`
- `status`
- `confidence`
- `review_date`
- `outcome`

## Sort

- Most recently modified or most recent `date` first.

## Use

- Review, filter, and maintain decisions records without importing raw source files directly.
