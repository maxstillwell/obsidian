# Meetings Database Setup

## Purpose

Use this setup note to create an Obsidian Bases view when the local Bases format is confirmed.

## Filter

- Include notes where `type` or folder location matches `meetings`.

## Display Fields

- `date`
- `project`
- `people`
- `company`
- `status`

## Sort

- Most recently modified or most recent `date` first.

## Use

- Review, filter, and maintain meetings records without importing raw source files directly.
