# Projects Database Setup

## Purpose

Use this setup note to create an Obsidian Bases view when the local Bases format is confirmed.

## Filter

- Include notes where `type` or folder location matches `projects`.

## Display Fields

- `project`
- `status`
- `area`
- `current_focus`
- `next_actions`
- `confidence`

## Sort

- Most recently modified or most recent `date` first.

## Use

- Review, filter, and maintain projects records without importing raw source files directly.
