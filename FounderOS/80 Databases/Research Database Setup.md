# Research Database Setup

## Purpose

Use this setup note to create an Obsidian Bases view when the local Bases format is confirmed.

## Filter

- Include notes where `type` or folder location matches `research`.

## Display Fields

- `topic`
- `source`
- `author`
- `date`
- `confidence`
- `status`

## Sort

- Most recently modified or most recent `date` first.

## Use

- Review, filter, and maintain research records without importing raw source files directly.
