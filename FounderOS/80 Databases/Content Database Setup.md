# Content Database Setup

## Purpose

Use this setup note to create an Obsidian Bases view when the local Bases format is confirmed.

## Filter

- Include notes where `type` or folder location matches `content`.

## Display Fields

- `status`
- `target_keyword`
- `product`
- `funnel_stage`
- `persona`
- `source_notes`

## Sort

- Most recently modified or most recent `date` first.

## Use

- Review, filter, and maintain content records without importing raw source files directly.
