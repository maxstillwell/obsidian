# Sources Database Setup

## Purpose

Use this setup note to create an Obsidian Bases view when the local Bases format is confirmed.

## Filter

- Include notes where `type` or folder location matches `sources`.

## Display Fields

- `source_type`
- `source_path`
- `source_url`
- `imported_at`
- `project`
- `area`
- `pii_level`
- `hash`

## Sort

- Most recently modified or most recent `date` first.

## Use

- Review, filter, and maintain sources records without importing raw source files directly.
