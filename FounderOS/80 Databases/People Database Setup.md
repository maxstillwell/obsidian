# People Database Setup

## Purpose

Use this setup note to create an Obsidian Bases view when the local Bases format is confirmed.

## Filter

- Include notes where `type` or folder location matches `people`.

## Display Fields

- `name`
- `company`
- `role`
- `relationship`
- `projects`
- `last_contact`

## Sort

- Most recently modified or most recent `date` first.

## Use

- Review, filter, and maintain people records without importing raw source files directly.
