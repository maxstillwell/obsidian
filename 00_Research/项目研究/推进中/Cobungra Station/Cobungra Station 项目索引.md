## 调研框架

### Thesis
- [ ] 资产本质判断：这是稳定经营型牧场，还是偏土地整合/长期增值型资产？
- [ ] 价值驱动拆解：面积、产权结构、水资源、租约安排、载畜能力、资本开支、退出流动性
- [ ] 收益模型框架：租金 / 自营 / 放牧 / 改良提升后的回报

### Due Diligence Workstreams
- [ ] 产权与边界：freehold titles、grazing licences、是否有 encumbrances / easements / access issues
- [ ] 水资源：water entitlement、works licence、water frontage licence、实际供水可靠性
- [ ] 经营能力：历史 DSE、季节性承载能力、草场质量、基础设施完整度
- [ ] 法律合同：lease、financial agreement、vendor statement、sale contract
- [ ] 成本结构：rates、licence fees、maintenance、fertiliser、capex
- [ ] 地图核对：freehold / licence / paddock / infrastructure 是否能一一对应

## 当前重点问题

- [ ] 项目总 freehold 面积是多少？grazing licence 面积是多少？
- [ ] 现有 lease 结构下，买方拿到的是空置交割还是带租约交割？
- [ ] FY25 / FY26 的 rates、water charges、licence fees 合计分别是多少？
- [ ] 历史 [[../../../../20_Knowledge/DSE（Dry Sheep Equivalent）|DSE]] 数据反映出的稳定承载能力大概是多少？
- [ ] 当前已知 capex 中，哪些是维持性投入，哪些是提升性投入？
- [ ] 水证、works licence、frontage licence 之间的关系是什么？

## 我们接下来可以怎么做

1. 先读 IM，做一版中文摘要与投资要点。
2. 再拆 title / grazing licence 结构。
3. 然后核算 recurring costs（rates、water、licence fees、rent）。
4. 最后搭一个初步投资判断框架。
