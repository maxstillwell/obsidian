# 大地块找地流程（Victoria）

## 目标

建立一套**每周固定执行**的大地块找地流程，持续从公开市场发现符合 MaxQi 投资逻辑的地块，并把“发现 -> 初筛 -> 进入研究”这条链路标准化。

当前重点：

- 区域：Victoria 为主
- 来源：`realestate.com.au`、`Domain`、`Real Commercial`
- 面积：`100 ha+`
- 优先级：`300 ha+`
- 数量目标：宁缺毋滥，以稳定发现高质量候选为主

## 一、我们在找什么

### 核心目标地块

优先寻找以下类型：

1. `300 ha+` 的农业大地块
2. `100 ha+` 且具备明确区域逻辑的大地块
3. 边界型、通道型、战略位置型地块
4. 兼具农业现金流和长期规划弹性的地块

### 当前不优先

以下类型原则上不进入本周重点清单：

1. `100 ha` 以下且没有明显战略逻辑的普通农地
2. 纯 lifestyle 小农场
3. 价格明显脱离区域比较基础、仅靠情绪挂牌的地块
4. 没有基本地址、面积或代理信息的低信息 listing

## 二、当前固定搜索入口

截至 `01-08-2026`，固定监控以下入口：

1. Realestate Victoria Rural  
   <https://www.realestate.com.au/buy/property-rural-in-vic/list-1>
2. Domain Victoria Rural  
   <https://www.domain.com.au/rural/?listview=1&mode=sale&sort=price-desc&state=vic>
3. Real Commercial Victoria Commercial Farming & Rural  
   <https://www.realcommercial.com.au/for-sale/vic/commercial-farming/>

说明：

- `Realestate` 和 `Domain` 更容易混入 lifestyle / farmlet。
- `Real Commercial` 的机构型、农企型、大体量资产比例通常更高。
- 因此周度扫描时，应先看 `Real Commercial`，再看 `Realestate` 和 `Domain`。

## 三、每周执行节奏

建议固定为**每周一次主扫描 + 一次补扫描**。

### 主扫描

- 时间：每周一或周二
- 目标：完成全量新盘扫描

### 补扫描

- 时间：每周四或周五
- 目标：
  - 检查新上市
  - 检查降价
  - 检查状态变化
  - 检查上周 shortlist 是否补资料

## 四、工作分三层

### 第一层：周度扫描

目标：

- 快速扫市场
- 找出本周值得看第二眼的地块

输出：

- 一份 `周度找地扫描` 笔记

### 第二层：单地块初筛

目标：

- 对 shortlist 地块做结构化记录
- 形成“值不值得进入研究”的初步判断

输出：

- 一份 `地块初筛笔记`

### 第三层：正式研究

目标：

- 对通过初筛的地块进入 `00_Research` 或 `10_Projects`
- 开始做规划、区域、用途、风险和退出逻辑研究

输出：

- 研究笔记 / 项目主档 / 报告草稿

## 五、每周标准动作

## Step 1：先看 Real Commercial

先扫大体量资产，因为这里的大地块密度通常最高。

重点记录：

- 新挂牌的大面积资产
- 机构型或 agribusiness 资产
- EOI / Expressions of Interest / Address available on request
- 过去几周持续在售但可能被忽略的地块

## Step 2：再看 Realestate

重点不是全看，而是筛出：

- `100 ha+`
- `300 ha+`
- 边界型区域
- Moorabool / Ballarat / Western corridor / growth influence 带

注意：

- `Realestate` 上 lifestyle 混入很多
- 很多 listing 虽然写 rural，但并不符合大地块逻辑

## Step 3：再看 Domain

Domain 的作用更像“交叉校验 + 补漏”。

重点检查：

- 是否有 Realestate 没出现的同类地块
- 同一地块在 Domain 上是否有更完整信息
- 是否存在价格、面积、代理描述差异

## Step 4：建立本周 shortlist

把本周所有值得再看的地块归入三类：

1. `A类`：建议立即进入单地块初筛
2. `B类`：先观察，等更多资料
3. `C类`：记录过，但暂不推进

## Step 5：对 A 类做单地块初筛

每个 A 类地块至少回答下面问题：

1. 面积够不够大？
2. 区域逻辑是否成立？
3. 用途逻辑是农业、边界增值还是其他战略用途？
4. listing 信息是否足够支撑进入下一步？
5. 有没有明显一票否决项？

## 六、单地块初筛的最低字段

每个候选地块至少记录：

- 地址
- 来源网站
- 链接
- Melbourne CBD 距离
- 当地 township 距离
- 面积
- 报价 / EOI / Contact Agent
- 每公顷价格
- agent
- 当前用途标签
- 所在 LGA / region
- 为什么进入 shortlist
- 初步风险
- 建议动作

## 七、建议的初筛判断标准

### A 类：进入研究

至少满足以下多数条件：

1. 面积 `100 ha+`，最好 `300 ha+`
2. 位于我们长期关注区域，或有明确区域逻辑
3. 不是单纯 lifestyle 逻辑
4. 有机会承接农业、边界增值或未来用途弹性
5. 信息足够支撑下一步做规划或区域研究

### B 类：观察

通常是：

1. 地块不错，但信息不够
2. 面积合格，但区域逻辑不清晰
3. 价格偏高，但值得继续跟踪
4. 可能需要等降价、补图纸或补 title 信息

### C 类：不推进

通常是：

1. 面积不符合
2. 明显偏 lifestyle
3. 区域逻辑不成立
4. 价格明显脱离比较基础
5. 有明显硬伤

## 九、当前最重要的原则

### 1. 不追求扫完所有 listing

目标不是“看完全部”，而是稳定抓到最值得看的那一小部分。

### 2. 先做市场发现，再做深研究

周度扫描阶段不做过深规划分析，避免一开始就陷入单个地块。

### 3. 一次只推进少数 A 类

每周建议只把 `1-3` 个地块推进到正式初筛，避免研究队列失控。

### 4. `00_Research` 是底稿区，不等于项目立项

看到值得研究，不代表已经值得买。先记录，再验证。

## 十、后续自动化方向

当前阶段先以人工流程为主。后续可以逐步半自动化：

1. 保存各平台固定搜索入口
2. 每周自动抓取新 listing 标题、面积、地区和链接
3. 自动识别 `100 ha+` 和 `300 ha+`
4. 自动生成周度扫描草稿
5. 人工只负责 shortlist 和判断

当前顺序建议是：

> 先把人工流程跑顺，再决定自动化什么。
