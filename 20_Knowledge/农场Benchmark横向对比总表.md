## 2. 从对比表里能直接读出的判断

### 2.1 资产类型不同，不能只用同一把尺子

- **Yaloak / Yarlok** 更像大规模混合经营平台，核心看土地组合、经营组织和水资源。
- **Qld 新农场** 更像成长型果园资产，核心看未来放量和灌溉兑现。
- **NSW 老农场** 更像需要重组的弱经营资产，核心看处置价值和债务压力。
- **Greystone / Buftons / Chintin** 目前更多是经营描述型资产，估值字段还不完整。

### 2.2 最适合横向比较的指标

后续若要把这些农场放进同一个投资模型，最实用的横向指标是：

- `价值 / ha`
- `已种植面积 / 总面积`
- `Revenue / ha`
- `Gross Margin / ha`
- `Debt / Value`
- `水权 / ML/ha`
- `成熟期是否明确`

### 2.3 现阶段最清晰的三类结论

1. **成熟混合经营平台**：Yaloak / Yarlok
2. **成长型果园资产**：Qld 新农场
3. **问题 / 重组型资产**：NSW 老农场

### 2.4 关于你说的“没有 /ha price 参考数据”

你这个判断是对的。严格来说，当前大部分资产**没有外部可比成交的 /ha price 参考**，所以不能把所有 /ha 数字都当成市场 benchmark。

更准确地说，当前只能分成三类：

- **可直接推导的 /ha 值**：例如 `Site Value ÷ 面积`、`CIV ÷ 面积`、`As Is Value ÷ 面积`
- **内部经营参考值**：例如 `Revenue / ha`、`Cost / ha`、`Gross Margin / ha`
- **暂缺市场 benchmark**：没有公开成交、没有完整估值报告、或资产边界不清

所以以后表里如果写 `/ha price`，最好明确标注是：

1. **估值推导值**，还是  
2. **可比成交值**。

两者不能混用。

## 3. 数据缺口清单

如果要把表继续升级，建议优先补这几项：

- Greystone：估值、负债、经营结果
- Buftons：估值、土壤/水资源、经营收益
- Chintin：估值、经营收益、资本开支需求
- Yaloak / Yarlok：如果要做更精细模型，补充单独地块面积和经营收益
