# 夏威夷果农场估值计算模板

> 这是一份可直接复用的工作模板。  
> 你以后只需要替换输入项，就可以重复估值。

## 1. 输入项

| 输入项 | 符号 | 示例（8 Powerline） | 你要替换的值 |
| --- | --- | ---: | --- |
| 总面积 | TA | 333.98 ha |  |
| 已建果园面积 | OA | 194.20 ha |  |
| Balance land 面积 | BA | 139.78 ha |  |
| 已建果园单价 | OR | A$60,000/ha |  |
| Balance land 单价 | BR | A$3,000/ha |  |
| 建筑/附属物价值 | BV | A$20,850 |  |
| 估值日期 |  | 23 Feb 2022 |  |
| 估值用途 |  | Mortgage security |  |

## 2. 标准公式

```text
已建果园价值 = OA × OR
Balance land 价值 = BA × BR
土地价值 = 已建果园价值 + Balance land 价值
总估值 = 土地价值 + BV
总面积单价 = 总估值 ÷ TA
已建果园单价 = 总估值 ÷ OA
```

## 3. 8 Powerline 工作样例

### 3.1 逐项计算

- 已建果园价值 = **194.20 × 60,000 = A$11,652,000**
- Balance land 价值 = **139.78 × 3,000 = A$419,340**
- 土地价值 = **A$12,071,340**
- 建筑/附属物价值 = **A$20,850**
- 总估值 = **A$12,092,190**
- Adopted value = **A$12,100,000**

### 3.2 反推单位值

- 总面积单价 = **A$12,100,000 ÷ 333.98 = A$36,250/ha**
- 已建果园单价 = **A$12,100,000 ÷ 194.20 ≈ A$62,300/ha**
- Balance land 单价 = **A$3,000/ha**

## 4. 可复用 benchmark

### 主基准

- **已建果园 benchmark：A$60,000/ha**
- **Balance land benchmark：A$3,000/ha**
- **水资源 benchmark：3.1 ML/ha**

### 校验范围

- **可比销售区间：A$60,000 – A$97,575 / planted ha**
- **总面积折算：A$36,250/ha**

## 5. 以后怎么用

1. 先判断新项目是 **young orchard** 还是 **mature orchard**；
2. 再从可比销售里选一个 orchard rate；
3. 用 balance land rate 算剩余土地；
4. 加上建筑和必要附属物；
5. 用总面积单价和已建果园单价做 sanity check；
6. 如果结果偏离太大，再回头查水、园龄、树数和流动性折价。

## 6. 适用范围

适用于：

- 已建果园或半成熟园
- 有明确面积拆分
- 有水权/灌溉信息
- 有 mortgage valuation 或 internal valuation 需求

不适用于：

- 纯空地
- 无法拆分 orchards / balance land 的资产
- 只能做经营模型、没有市场估值数据的项目
