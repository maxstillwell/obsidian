# 夏威夷果农场估值基准

> 说明：这份笔记只提炼**夏威夷果（macadamia）农场**的估值基准。  
> 不包含 Yaloak、Greystone、Chintin 等无关资产。
>
> 这里的“benchmark”分两类：  
> 1. **估值报告里真正用来定价的基准**；  
> 2. **经营模型里支持估值判断的基准**。  
> 两者不要混成一个口径。

## 1. 估值机构给夏威夷果农场定价时，最看重什么

从你现有的估值/分析材料看，评估机构并不是只看“每公顷多少钱”，而是把下面几组因素合起来：

### 1.1 资产状态

- 是**成熟老园**，还是**年轻新园**；
- 已经建好多少果园面积；
- 还有多少 **balance land / 可扩种土地**；
- orchard plan 是否现代、是否规范；
- 道路、建筑、附属设施状态如何。

### 1.2 水和灌溉

- 是否有正式水权 / water allocation；
- 是否有 dam / 储水；
- 当前供水对**现在树龄**是否够；
- 未来成熟后是否还会出现水缺口；
- 是否需要额外补水或扩容。

### 1.3 果园成熟度

- 树龄结构；
- 首次采收时间；
- 商业化放量时间；
- 成活率 / 健康状况；
- 排水与病害风险。

### 1.4 交易和流动性

- 公开市场买家是否有限；
- 大额农村资产是否存在流动性折价；
- 是否有可比销售；
- 估值是 **As Is market value**，还是 **Alternate Use**。

## 2. 从你现有几份夏威夷果报告里抽出来的基准

### 2.1 [[10_Projects/夏威夷果农场/Qld新农场]]

这份是最标准的 **rural mortgage security valuation** 口径。

**估值基准：**

- **Market Value (As Is)**：A$12.1m
- **总面积**：333.98 ha
- **已建果园面积**：194.20 ha
- **balance land**：139.78 ha
- **价值 / 总面积**：约 A$36.25k/ha
- **价值 / 已建果园面积**：约 A$62.3k/ha
- **balance land 折算**：约 A$3k/ha

**评估机构关心的点：**

- 是否是现代 orchard plan；
- 现有灌溉是否足够支撑当前树龄；
- balance land 还有多少价值；
- 成熟后是否会出现水缺口；
- 估值不是看当前现金流，而是看“已投入 CAPEX + 未来放量”的资产价值。

**这份报告里最重要的 benchmark：**

- `已建果园面积 / 总面积`
- `As Is market value`
- `价值 / total ha`
- `价值 / established orchard ha`
- `树龄是否接近稳产`
- `未来 2-5 年放量路径`
- `水权/储水是否支撑成熟园`

### 2.2 [[10_Projects/夏威夷果农场/NSW老农场]]

这份更像 **经营下行 + 资产重组** 口径。

**估值基准：**

- 四块地的 as-is 估值合计约 **A$27.915m**
- alternate use 合计约 **A$15.65m**
- 总种植面积约 **400+ ha**
- 单位产量约 **2 t/ha**
- 每公顷收入约 **A$8,000**
- 每公顷管护成本约 **A$7,000–8,000**
- 不考虑利息时接近盈亏平衡

**评估机构关心的点：**

- 哪些地块是核心资产，哪些可以卖；
- 经营是否还能支撑当前资产价值；
- 土地和果园的价值是否被债务压力侵蚀；
- alternate use value 能保多少下行保护；
- 估值是否受 powerline、easement、access、水权、树龄等约束影响。

**这份报告里最重要的 benchmark：**

- `收入 / ha`
- `成本 / ha`
- `产量 / ha`
- `as-is value / ha`
- `alternate use value / ha`
- `债务压力`
- `核心 / 非核心资产拆分`

### 2.3 [[10_Projects/夏威夷果农场/夏威夷果农场 - 三表汇总终稿]]

这份不是估值报告，但它给了**经营模型里的关键价格和产能基准**，能反过来支持估值判断。

**关键基准：**

- NIS Purchase Cost：**A$4/kg**
- Kernel Selling Price：**A$23.475/kg**
- Kernel Yield Rate：**33%**
- NIS Processing Loss Rate：**7%**
- Moisture Loss：**8%**

**对估值的意义：**

- 它说明夏威夷果农场的价值，不只是地值，而是和**出仁率、原料成本、加工转化率、销售价格**联动；
- 如果产量和回收率能稳定，经营性价值会显著高于单纯土地价值；
- 如果原料价格、产量或出仁率下滑，估值会很快被压缩。

## 3. 夏威夷果农场最该统一的 benchmark

如果你要以后拿这些报告做投资模型，建议统一下面这些字段：

| 维度 | Benchmark | 用途 |
| --- | --- | --- |
| 面积 | 总面积 ha | 判断资产规模 |
| 面积 | 已种植面积 ha | 判断有效产能 |
| 面积 | balance land ha | 判断扩种潜力 |
| 估值 | As Is Market Value | 判断当前市场价值 |
| 估值 | Alternate Use Value | 判断下行保护 |
| 估值 | Value / total ha | 判断总地值 |
| 估值 | Value / planted ha | 判断已建果园价值 |
| 水利 | ML/ha | 判断成熟后供水边际 |
| 生产 | Yield / ha | 判断产出能力 |
| 生产 | Bearing / mature area | 判断有效产能 |
| 果园 | Tree age / maturity | 判断放量阶段 |
| 果园 | First harvest / full commercial year | 判断现金流启动时间 |
| 经营 | Revenue / ha | 判断收入强度 |
| 经营 | Cost / ha | 判断成本强度 |
| 经营 | Gross margin / ha | 判断经营效率 |
| 交易 | Comparable sale / ha | 判断市场锚点 |
| 风险 | Liquidity discount | 判断大额农场退出折价 |

## 4. 对夏威夷果农场来说，最关键的 5 个判断因子

1. **水是否够**  
   当前够不够不够重要，关键是成熟后够不够。

2. **园龄是否进入放量期**  
   年轻新园和成熟老园，价值逻辑完全不同。

3. **已建果园面积占比**  
   已建面积越大，资产确定性越强。

4. **单产能否稳定**  
   夏威夷果不是“种了就有钱”，而是看长期单产和回收率。

5. **大额资产流动性折价**  
   农场不是标准化流通商品，退出时常常要打折。

---

## 5. 一句话总结

**夏威夷果农场的估值基准，不是单纯的 /ha 土地价，而是“已建果园面积 + 水资源 + 园龄成熟度 + 未来放量路径 + 流动性折价”一起决定。**

如果再进一步，经营模型里的核心基准就是：  
**产量 / ha、收入 / ha、成本 / ha、出仁率、核仁售价。**
